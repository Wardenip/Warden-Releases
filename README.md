# Warden

Public releases and installation files for Warden.

## About

Warden is an Android automation, monitoring, and recovery system designed to keep Android devices online and manageable.

This repository contains **public releases and distribution files**.

The main Warden source code is maintained in a separate private repository.

## Releases

Stable builds are published in [GitHub Releases](../../releases).

## Installation

Installation is performed using the Warden bootstrap script.

More installation instructions will be added with the first public release.
